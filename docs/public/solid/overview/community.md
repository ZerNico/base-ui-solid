# Community

Learn where to get help with base-ui-solid, how to contribute, and how to stay up to date.

## Get help and contribute

### GitHub

base-ui-solid is an open-source project.
If you want to file a bug report or contribute, visit our <a href="https://github.com/OWNER/base-ui-solid">GitHub</a>.

Bugs that also reproduce with upstream [Base UI](https://base-ui.com) are best reported to the [upstream repository](https://github.com/mui/base-ui) and are picked up by the port when it syncs.

## Upstream Base UI

base-ui-solid ports [Base UI](https://base-ui.com), which has its own ecosystem of styled libraries and community channels.
Those projects are built for React and can't be used directly with this Solid port, but their designs and patterns often carry over.

## Stay up to date

### GitHub releases

You can subscribe to the <a href="https://github.com/OWNER/base-ui-solid/releases">GitHub releases</a> to get notified.

Detailed release notes are published on our [releases](/solid/overview/releases.md) page as well.
