# Releases

Release notes for base-ui-solid, the Solid port of Base UI.

base-ui-solid has not been released yet.

Each release ports a specific upstream [Base UI](https://base-ui.com) commit, so component behavior
and APIs follow the matching `@base-ui/react` release. Its release notes list the upstream
version it tracks and any Solid-specific changes.
