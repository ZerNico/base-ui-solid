## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Field } from 'base-ui-solid/field';

<Field.Root>
  <Field.Label />
  <Field.Control />
  <Field.Description />
  <Field.Item />
  <Field.Error />
  <Field.Validity />
</Field.Root>;
```
