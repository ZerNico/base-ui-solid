## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Progress } from 'base-ui-solid/progress';

<Progress.Root>
  <Progress.Label />
  <Progress.Track>
    <Progress.Indicator />
  </Progress.Track>
  <Progress.Value />
</Progress.Root>;
```
