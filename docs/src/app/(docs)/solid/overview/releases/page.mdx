# Releases

<Subtitle>Changelogs for each Base UI Solid release.</Subtitle>
<Meta name="description" content="Release notes for Base UI Solid, the Solid port of Base UI." />

Base UI Solid has not been released yet.

Each release ports a specific commit from the main branch of upstream [Base UI](https://base-ui.com).
That commit can include changes upstream hasn't released yet, so a Base UI Solid release can be ahead
of the latest `@base-ui/react` release. Its release notes list the upstream commit it tracks, the
`@base-ui/react` release it builds on, and any Solid-specific changes.
