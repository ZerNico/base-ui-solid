# Base UI Solid

An unofficial Solid port of [Base UI](https://base-ui.com), the unstyled UI component library for building accessible user interfaces. Not affiliated with the Base UI team.

---

## Documentation

To get started, check out the [Base UI Solid documentation](https://base-ui-solid.pages.dev/solid/overview/quick-start).

## Contributing

The port follows Base UI file by file. [`PORTING.md`](/PORTING.md) describes how React code translates to Solid, and [`UPSTREAM.md`](/UPSTREAM.md) how upstream changes are synced.

## Releases

To see the latest updates, check out the [releases](https://base-ui-solid.pages.dev/solid/overview/releases).
